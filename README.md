# SmartCloset 

Armario inteligente con interacción por gestos, voz y movimiento del cuerpo. Creado por Lidia Valera López (100522236), Rodrigo Melero Moreno (100522305) y Lidia Blanco García (100522209) para la asignatura Sistemas interactivos y ubicuos.


## Requisitos Previos
- Tener instalado **Node.js** (v18 o superior).
- Recomendamos ejecutar el código en Linux.
- Acceder a 'chrome://flags/#unsafely-treat-insecure-origin-as-secure'y habilitar el enlace dado por terminal (hasta el puerto :3000)

## Instalar las dependencias
Ejecuta por terminal el siguiente comando

```bash
npm install
```

## Ejecuta el servidor web
Ejecuta el servidor web con el siguiente comando:

```bash
npm start
```

## Pantallas y URLs
Accede a la URL de espejo desde el dispositivo que quieras usar como pantalla y a la URL de mando con el dispositivo que quieras usar de controlador.
